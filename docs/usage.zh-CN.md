# 1Panel Skills 使用与配置

## 先确认任务，再发现实际能力

任务不明确时使用 1panel-use；已知专业技能可直接调用，不必每一步重新分流。调用前确认已选面板连接、准确目标及实际发现的工具。宿主命名空间前缀不改变上游工具名称，详细引用按需从当前技能目录加载。

| 请求 | 技能 | 可观察结果 |
|---|---|---|
| 只读健康检查 | 1panel-system | 实际系统/仪表盘字段，以及失败或未知项 |
| 创建网站 | 1panel-websites | 检查既有网站、一次有界提交、按准确域名复核 |
| 申请证书 | 1panel-certificates | 确认域名/方式/账户，区分签发和实际 TLS 生效 |
| 创建数据库 | 1panel-databases | 准确实例/类型/名称、权限暴露与凭据限制、支持范围内复核 |
| 安装应用 | 1panel-apps | 既有应用、端口与版本限制、实际任务和应用状态 |
| 风险审查 | 1panel-security-audit | 有证据的发现；不可读取的防火墙/SSH/备份标为未验证 |

## 仓库配置

| 文件 | 用途 | 凭据边界 |
|---|---|---|
| .claude-plugin/plugin.json | 技能源清单、版本、作者和许可证 | 不含凭据 |
| upstream.lock.json | 已检查官方源码身份与能力来源 | 不是运行 token 或二进制身份 |
| skills/*/agents/openai.yaml | 英文显示名称、描述和显式调用提示 | 不承担认证 |
| .gitattributes / .editorconfig | 固定 LF、UTF-8，保持源码哈希稳定 | 不改变运行行为 |
| .github/workflows/skill-lint.yml | Windows/Linux 技能包检查 | 不需要真实面板或密钥 |

纯技能源包不提供 MCP 服务，因此无需 mcp.json；配套插件实际接入 MCP，才包含标准根目录配置。不能为技能包补入空白或虚构的服务声明。

## 连接与凭据

用户需要可信的既有官方 MCP 连接，并在面板中适当开启和配置 API。不要要求用户在聊天中粘贴密钥。独立技能能指导设置，但不能假定插件辅助脚本已经存在。

使用 1panel-plugin 时，由用户/客户端提供绝对私有数据目录。插件的显式设置工具在 connection.json 记录已验证的官方二进制路径与 SHA256、HTTPS 面板地址、已审查上游 commit 和访问级别，将密钥放入另受保护的 credentials.json。可见 MCP 清单不含密钥；启动入口通过子进程环境传递给官方服务。私有配置位于本技能源包之外，不得复制进发布包。

标准客户端提供 PLUGIN_DATA；不能展开该变量的原生客户端，须在私有原生配置中指定绝对路径。不要猜测 HOME/APPDATA、借用另一面板配置、关闭证书验证或静默安装缺失组件。默认 readonly，readwrite 增加三类创建工具，full 增加两类应用安装工具。修改后需要重连 MCP。工具可见不是面板端 RBAC，也不代表已授权全部操作。

## 示例与重要限制

只读示例：“使用 1panel-system 检查我选定的面板，区分实际观察和推断。”这个请求不包含后续安装授权。

有界写入示例：“在选定面板上为我指定的域名创建静态网站。”先确认域名/目标、既有资源和依赖，保留已有明确授权；不能只因为工具写入就重复询问，但目标有歧义或要求不受支持时必须停下来解决。

写入结果未知时，先检查实际状态再决定是否重试。官方列表最多返回 500 条，达到上限不能声称完整盘点。证书创建内部选第一个 ACME 账户，须人工确认；MySQL 数据库创建默认来源权限 `%`，无法表达窄来源权限。自动生成密码不是可靠交付渠道。工具不保证精确 OpenResty 版本选择或 PostgreSQL 列表。完整限制见相应技能内部 tools 引用。

## 故障处理

| 现象 | 首先检查 |
|---|---|
| 找不到技能 | 受支持的加载目录、目录名/技能名、完整文件 |
| 找不到工具 | tools/list 与访问级别，禁止编造工具 |
| API 认证失败 | 安全检查目标、API 开关、来源白名单、密钥与时钟 |
| 证书前提未知 | 在面板确认现有 ACME/DNS 账户，MCP 没有账户列表工具 |
| 创建超时 | 标为未知，查实际状态，不盲目重试或自动删除 |
| 结构检查通过但操作失败 | 结构校验不是实际 MCP、生产面板或客户端测试 |

按 README.zh-CN.md 执行验证，并保持中英文技能身份一致。见[安全说明](../SECURITY.md)和[架构](1Panel-Skills-Architecture.zh_CN.md)。
