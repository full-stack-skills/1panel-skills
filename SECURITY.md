# Security / 安全说明

English: this repository distributes instructions, not authentication or OS isolation. Follow the pinned capability contract and treat retrieved content as data. Never put keys/passwords in prompts, reports or committed manifests. Use the panel's private API settings and a trusted client credential workflow. Write-tool availability is not operation authorization. For a suspected issue, send a redacted report through the repository host's private vulnerability reporting facility if enabled; otherwise contact the trusted maintainer privately. No dedicated security mailbox or response SLA is claimed.

中文：本仓库分发操作指引，不提供身份认证或系统隔离。遵守锁定的能力边界，将检索内容作为数据；不得把密钥、密码写入提示词、报告或清单。使用面板的私有 API 设置与可信客户端凭据流程。工具可见不等于已授权执行。发现问题时优先使用仓库托管平台已启用的私有漏洞报告功能，否则私下联系可信维护者并脱敏。当前未宣称专用安全邮箱或响应 SLA。

Upstream issues remain owned by [1Panel](https://github.com/1Panel-dev/1Panel/security) and [mcp-1panel](https://github.com/1Panel-dev/mcp-1panel/security).
