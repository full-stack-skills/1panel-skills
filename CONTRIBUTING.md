# Contributing / 贡献指南

English: update original skills, their local references and both README catalogs together. Match actual tools/schemas from upstream.lock.json; document restrictions and failure handling. Run the three checks in README.md. Changes to the official pin or operating permissions require corresponding integration tests in 1panel-plugin. Do not include credentials or test a production panel in CI. Obtain authorization before branch creation, dependency installation or publication.

中文：技能源码、技能内部引用和中英文目录须同步维护。依据 upstream.lock.json 锁定的实际工具与参数记录能力、限制和异常处理；执行 README.zh-CN.md 中的三项检查。上游版本或权限变化须同时更新 1panel-plugin 的集成测试。禁止提交凭据，禁止在 CI 中操作生产面板。创建分支、安装依赖或发布前须获得授权。
